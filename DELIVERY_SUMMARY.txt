🛠️ TECHNICAL SPECIFICATIONS
================================================================================

Architecture:
  File Upload → Text Splitting → Embedding → Vector Store → Retrieval → LLM → Answer

Components:
  1. CharacterTextSplitter - Breaks documents into chunks
  2. OpenAIEmbeddings - Converts text to numerical vectors
  3. Chroma - Vector database for semantic search
  4. RetrievalQA - Combines retriever with LLM
  5. OpenAI LLM - Generates answers
  6. Streamlit - Web interface

Language: Python 3.7+
Framework: Streamlit (web app)
LLM: OpenAI (GPT-3.5-turbo)
Embeddings: OpenAI embeddings model
Vector DB: Chroma
Code Quality: PEP8 compliant, fully documented
